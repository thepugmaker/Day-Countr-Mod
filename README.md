# About this mod
This is a day counter mod that counts the days and displays it on screen. This mod works with all resolutions and only works with the fabric mod loader. It's even open source so if you ever want to make your own features, and you know Java, and the fabric mod loader well enough go ahead and fork this project!
# How to build
`Intellij IDEA`:
Open the project in `Intellij`, Open the folder with all the code in it, go into gradle and then tasks and find build, 
After you find build Run it, and then you'll see in the `builds`.`libs` folder will be the `dayconuntr-(version).jar` and then thats the build!
Good job you have now built my mod!
`Eclipse`: not supported
